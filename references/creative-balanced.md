# 均衡创作增强

仅在用户明确允许合理创作、不要求极致摄影真实性时使用；这是用户选择的目标，不是失败后的自动兜底。按目标风格分流：摄影风格最高 6K，其他风格最高 12K；超限直接拒绝，不自动更换尺寸或后端。

优先级：人物特征、表情、构图和文字 → 连续景深与光照 → 有层次且协调的细节 → 时间、内存和磁盘开销。允许有摄影感的重建纹理、适度风格化和不可认证的微细节；不声称真实恢复或等效12K。

材质按画面尺度评价：衣物类别、纹理方向、褶皱和光照一致，焦内有细节且不抢过人脸即可。无需逐根解析纱线或证明真实毛孔。仍拒绝改脸、改表情、添牙、伪字、重复纹理、突兀毛网、过锐光晕、拼接块和景深突变。

先在原像素核对已有候选，同一输入/参数已运行的裁剪允许按新目标形成独立复核文件；引用旧报告和用户目标变化，保留旧失败结论，不改变运行哈希或原始报告。仅目标改变不能证明旧缺陷消失。新源图或参数仍须新裁剪；既有候选符合新目标时不为重新绑定相同像素重复推理。

当前混合方案保持MPS编码/特征、已校验ANE优先DiT/解码、seed42与wavelet低频对齐；它们是本图已执行配置，不是跨图最优参数。最多一次全图4倍推理，原生人脸包一次合成。禁止追加超分、噪声与锐化来冒充细节。已有高密度修复不缩回母版。

按现有review、approval、repair、trial与final哈希合同验收；不关闭检查、不添加失败后自动换模型。不改写历史严格摄影失败。新目标仍须逐人、衣料、手、文字、景深、所有接缝检查，最终通过后才交付。
